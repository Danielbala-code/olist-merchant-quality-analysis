# Data

Download the **Brazilian E-Commerce Public Dataset by Olist** from:

https://www.kaggle.com/olistbr/brazilian-ecommerce/home

Extract the nine source CSV files into `data/raw/`. Raw data is deliberately excluded from Git because the source is licensed separately and can be reproduced from the official publisher.
